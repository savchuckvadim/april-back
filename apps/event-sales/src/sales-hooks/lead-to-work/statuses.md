В рамках проекта настраиваются три связанные воронки продаж:
№	Название воронки	Назначение
1	Воронка холодного обзвона (лиды)	Обработка входящих заявок с сайта, первичный контакт, квалификация
2	Воронка презентации	Этап демонстрации продукта, подготовка коммерческого предложения
3	Основная воронка сделки	Полный цикл сделки от холодного обзвона до передачи в ОС
Принцип движения: Лид последовательно проходит через все три воронки. При переходе на следующий этап в текущей воронке автоматически создаётся сделка в следующей воронке (либо осуществляется перевод сделки между воронками).

3. Воронка №1: Холодный обзвон (обработка лидов)
Назначение: Обработка входящих заявок с сайта, первичный контакт с лидом, квалификация и определение дальнейших действий.
Стартовая точка: Лид поступает в воронку автоматически с сайта (через лид-форму).
Этапы и их логика:
Этап 1: ЛИД (заявка с сайта)
•	Описание: Новая заявка, поступившая с сайта.
•	Признаки: Заполнена контактная форма, присвоен UTM-меткам для сквозной аналитики.
•	Автоматические действия: Назначение ответственного менеджера (по очереди или по региону).
Этап 2: ЗВОНИЛ (в работе)
•	Описание: Менеджер совершил первый звонок по лиду.
•	Признак: Зафиксирован факт звонка (ручное переключение или через интеграцию с телефонией).
•	Обязательное поле при переходе: Дата и время звонка, комментарий по результату разговора.
Этап 3: ДОЗВОНИЛСЯ / НЕ ДОЗВОНИЛСЯ
•	Вариант 3.1: НЕ ДОЗВОНИЛСЯ
•	Действие: Автоматическая постановка задачи на перезвон.
•	График перезвонов (по порядку):
•	Через 30 минут
•	Через 60 минут
•	Через 180 минут (3 часа)
•	Через 24 часа (1 сутки)
•	Через 24 часа (ещё 1 сутки)
•	Через 7 суток
•	Примечание: Если после всех попыток дозвониться не удалось — сделка автоматически закрывается как «неактуальная» (или остаётся в статусе «не дозвонились» для архивации).
•	Вариант 3.2: ДОЗВОНИЛСЯ
•	Действие: Менеджер определяет дальнейший сценарий (переход на один из этапов ниже).
Этап 4: ПЕРЕЗВОН (клиенту неудобно говорить)
•	Описание: Клиент ответил, но не может говорить в данный момент.
•	Признак: Клиенту неудобно говорить.
•	Действие: Автоматическая постановка задачи на перезвон в удобное для клиента время (указывается менеджером вручную).
Этап 5: БРАК (не целевая аудитория)
•	Описание: Лид не соответствует целевой аудитории.
•	Признаки (выбираются из списка):
•	Чужой ОК (объект коммерческой недвижимости / организация)
•	Свой ОК
•	Частный запрос (не соответствует B2B-сегменту)
•	Действие: Сделка закрывается с причиной «брак» и не переходит в следующие воронки.
Этап 6: ОТКАЗ ОТ ОБЩЕНИЯ
•	Описание: Клиент отказался от дальнейшего общения.
•	Причины (выбираются из списка):
•	Не интересно
•	Есть СПС (собственная программная система / альтернативное решение)
•	Не прошёл секретаря
•	Чужой ОК
•	Свой ОК
•	Действие: Сделка закрывается как «отказ» с указанием причины.
Этап 7: НАЗНАЧЕНА ПРЕЗЕНТАЦИЯ
•	Описание: С клиентом согласована дата и время презентации продукта/услуги.
•	Действие: Автоматическое создание задачи «Провести презентацию» на указанную дату. Сделка переходит в Воронку №2 (Презентация).
Этап 8: КЛИЕНТ НА РЕШЕНИИ
•	Описание: Клиенту направлены коммерческие документы, он принимает решение.
•	Признаки (заполняются менеджером):
•	Направлено КП (коммерческое предложение)
•	Направлен проект договора
•	Направлен счёт
•	Действие: Сделка переходит в Воронку №3 (Основная сделка) на этап «Клиент на решении».

4. Воронка №2: Презентация
Назначение: Управление этапом демонстрации продукта и подготовки коммерческих документов.
Стартовая точка: Сделка попадает в эту воронку из Воронки №1 при наступлении этапа «Назначена презентация».
Этапы и их логика:
Этап 1: ПРЕЗЕНТАЦИЯ НАЗНАЧЕНА
•	Описание: Презентация запланирована.
•	Автоматические действия: Создание задачи «Провести презентацию» с уведомлением менеджеру.
Этап 2: ПРЕЗЕНТАЦИЯ ПРОВЕДЕНА
•	Описание: Презентация состоялась.
•	Действие: Менеджер фиксирует результат и определяет дальнейший сценарий.
Этап 3: ДОРАБОТКА
•	Описание: Клиент не готов к покупке сейчас, требуется возврат позже.
•	Признак: Вернуться позже.
•	Причины (выбираются из списка):
•	Не нравится система
•	Дорого
•	Другая СПС (альтернативное решение)
•	Нет денег
•	Не будет обсуждать с ЛПР (лицом, принимающим решения)
•	Действие: Сделка остаётся в воронке с пометкой «доработка». Автоматическая задача на перезвон через указанный менеджером срок.
Этап 4: КЛИЕНТ НА РЕШЕНИИ
•	Описание: После презентации клиенту направлены коммерческие документы.
•	Признаки (заполняются менеджером):
•	Направлены КП
•	Направлен проект договора
•	Направлен счёт
•	Есть дата звонка по решению (обязательное поле)
•	Действие: Сделка переходит в Воронку №3 (Основная сделка) на этап «Клиент на решении».

5. Воронка №3: Основная сделка (полный цикл)
Назначение: Полное управление сделкой от квалифицированного лида до передачи в отдел сопровождения (ОС).
Стартовая точка: Сделка попадает в эту воронку:
•	Из Воронки №1 при этапе «Клиент на решении»
•	Из Воронки №2 при этапе «Клиент на решении»
Этапы и их логика:
Этап 1: ХОЛОДНЫЙ ОБЗВОН
•	Описание: Первичная обработка лида (технически дублирует начало Воронки №1, но может использоваться как отдельный этап для уже квалифицированных лидов).
Этап 2: ПЕРЕЗВОН
•	Описание: Клиенту неудобно говорить, требуется перезвон.
Этап 3: ПРЕЗЕНТАЦИЯ
•	Описание: Проведение презентации (может дублировать Воронку №2, либо интегрироваться с ней).
Этап 4: КЛИЕНТ НА РЕШЕНИИ
•	Описание: Клиент рассматривает коммерческое предложение.
•	Признаки (заполняются менеджером):
•	Направлены КП
•	Направлен проект договора
•	Направлен счёт
•	Есть дата звонка по решению
Этап 5: ДОРАБОТКА
•	Описание: Клиент не готов к покупке сейчас.
•	Причины (выбираются из списка):
•	Не нравится система
•	Дорого
•	Другая СПС
•	Нет денег
•	Не будет обсуждать с ЛПР
•	Действие: Автоматическая задача на перезвон.
Этап 6: ЖДЁМ ОПЛАТУ
•	Описание: Клиент принял положительное решение, выставлен счёт, ожидается оплата.
•	Признак: Выставлен счёт, отправлен клиенту.
•	Автоматические действия: Создание задачи «Контроль оплаты» с напоминанием через 1, 3, 7 дней.
Этап 7: ПРОДАЖА (сделка успешна)
•	Описание: Оплата получена, сделка закрыта с положительным результатом.
•	Признак: Поступила оплата (в ручном режиме или через интеграцию с 1С/банком).
•	Действие: Сделка переходит в статус «Успешно».
Этап 8: ПЕРЕДАЧА В ОС (отдел сопровождения)
•	Описание: Сделка передана в отдел сопровождения / клиентский сервис для дальнейшего обслуживания.
•	Признак: Назначен ответственный из ОС.
•	Действие: Создание задачи для отдела сопровождения, закрытие сделки.

6. Статусы и признак
Для каждого этапа настраиваются:
•	Название стадии (отображается в канбан-доске)
•	Вероятность закрытия сделки (%)
•	Цвет (для визуального разделения этапов)
•	Текст подсказки (инструкция для менеджера на этапе)
Обязательные поля при переходе между этапами:
•	Переход на этап «Клиент на решении» → обязательно заполнить поля: «Направлены КП», «Направлен проект договора», «Направлен счёт», «Дата звонка по решению».
•	Переход на этап «Отказ» / «Брак» → обязательно указать причину из справочника.
•	Переход на этап «Продажа» → обязательно указать сумму сделки и дату оплаты.

7. Автоматические бизнес-процессы (роботы)
Настраиваются следующие автоматические действия (бизнес-процессы / роботы):
Триггер	Действие
Лид поступает с сайта	Создание сделки в Воронке №1, назначение менеджера
Этап «НЕ ДОЗВОНИЛСЯ»	Создание задачи на перезвон (по расписанию: 30 мин → 60 мин → 180 мин → 24 ч → 24 ч → 7 сут)
Этап «ДОЗВОНИЛСЯ» → «Назначена презентация»	Создание задачи «Провести презентацию»
Этап «Назначена презентация» (за день до)	Уведомление менеджеру о предстоящей презентации
Этап «Ждём оплату» (день 1, 3, 7)	Уведомление менеджеру «Проверить статус оплаты»
Этап «ДОРАБОТКА»	Создание задачи на перезвон через указанный срок
Этап «Продажа»	Уведомление РОП, создание задачи для ОС
Любое изменение стадии	Логирование в историю сделки

8. Требования к карточке сделки
В карточке сделки должны быть доступны следующие пользовательские поля:
Название поля	Тип	Назначение
Причина отказа / брака	Список (выбор одного)	Фиксация причины закрытия
Направлены КП	Дата + Чекбокс	Фиксация отправки КП
Направлен проект договора	Дата + Чекбокс	Фиксация отправки договора
Направлен счёт	Дата + Чекбокс	Фиксация отправки счёта
Дата звонка по решению	Дата	Контрольный срок для звонка
Удобное время для перезвона	Дата + Время	Для этапа «Перезвон»
Сумма сделки	Число	Фиксация суммы
Источник лида	Список	Аналитика по каналам
