# Стили PDF-КП

Встроенные стили коммерческого предложения: как устроены, как добавить новый,
и каталог референсов владельца (Canva, 15.11.2026).

## Как устроено

```
templates/
  kit/                 общее для всех стилей, красится темой
    theme/             OfferPdfTheme (цвета, кегли, поля, шрифты), themedStyles
    document/          OfferPdfDocument (титульник → страницы), OfferSections, PageNumber
    letter/ price/ infoblocks/ stamps/   блоки КП
    decor/             векторная декорация (GlassStripes — «рифлёное стекло»)
    lib/               текст, менеджер, содержимое титульника
  classic/             «Классический»: тема + шапка/подвал
  prism/               «Призма»: тема + титульник, шапка/подвал, подложка
  monochrome/          «Монохром»: серый лист, Manrope, вкладка у края, титульник по вордовским
  offer-pdf-template.registry.ts   список стилей
```

Стиль — это `OfferPdfTemplate`:

- **тема** (`OfferPdfTheme`) — всё, чем общие блоки отличаются: цвета, кегли, поля, шрифты;
- **оформление листа** (`OfferPdfChrome`): `Header`, `Footer` (fixed, их высота задаёт поля),
  необязательные `Cover` (титульник отдельной страницей) и `Underlay` (подложка каждой страницы);
- `hasCover` — есть ли титульник (включается настройкой `withCover`);
- `lockedSettings` — настройки, которые стиль задаёт сам: рендер ставит их поверх выбора
  менеджера, фронт по списку стилей гасит эти переключатели.

Тема передаётся пропсом, без React-контекста: тесты обходят дерево, вызывая компоненты как функции.

Превью стиля для выбора: `GET /api/offer-pdf/templates/:code/preview` — первая страница на
образце «Гарант-Офис» (`lib/sample-offer-pdf-model.ts`), кэш в памяти до перезапуска.

## Как добавить стиль

1. Папка `templates/<code>/`: `<code>.theme.ts`, `components/` (шапка, подвал, по желанию титульник
   и подложка — по компоненту на файл, стили через `themedStyles`), `<code>.template.tsx`.
2. Код в `OfferPdfTemplateCode`, шаблон в `OFFER_PDF_TEMPLATES`.
3. Тест в `__tests__/` по образцу `prism.template.spec.ts`.
4. `npm run offer-pdf:audit -- --out tmp/offer-pdf-audit` — все сценарии во всех стилях,
   «Проблем нет»; глазами посмотреть PDF из `--out`.

## Правила оформления

- **Вектор в первую очередь.** Градиенты (линейные и радиальные), полосы, плашки, линии, сетки,
  повёрнутый текст react-pdf рисует сам: файл лёгкий, печатается чётко, цвет берётся из темы.
- **Картинка — только для того, что вектором не сделать**: размытие, зерно, тени, режимы
  наложения, 3D. Картинка печатного качества добавляет к файлу ~300–600 КБ.
- **Подложка внутренних страниц — бледная и в поле листа**, под текст не заходит.
  Тёмный фон — только на титульнике: внутри его плохо печатать и таблицы читаются хуже.
- **Шрифты**: статические TTF (не variable, не woff2), с кириллицей, лицензия OFL или иная,
  разрешающая встраивание. Регистрируются в `fonts/offer-pdf-fonts.ts`, лицензии рядом
  (`files/OFL-*.txt`). Сейчас: PT Sans (классика), Manrope 300/400/600/700, Montserrat
  400/700/900. Курсива у Manrope и Montserrat нет — он зарегистрирован прямым начертанием.
  Неиспользуемое семейство в PDF не встраивается и размер не трогает.
- **Интерлиньяж не вешать на `Page`**: у динамического текста (номер страницы) любой предок с
  `lineHeight` гасит строку. Безразмерный `lineHeight` react-pdf переводит в пункты по кеглю узла,
  где он задан, — рядом с ним всегда ставить `fontSize`. Потомки наследуют уже пункты: крупный
  заголовок в строке обёртки наезжает на следующую, поэтому `h2` крупнее строки задаёт свой.
- **Украшения листа — fixed в боковом поле** (вкладка, полосы): шапкой и подвалом не считаются,
  поля под себя не раздвигают (`isSideDecoration`). Всё fixed на титульнике (лист без полей) —
  тоже оформление (`isDecoration`). Повёрнутый текст лежит в раскладке неповёрнутым и вылезает
  из поля — поэтому украшение определяется по fixed-корню.
- **Титульник — по образцу вордовских шаблонов**: главное на нём — комплект и поставка
  («Модерн»: «Гарант / комплект / поставка»), клиент с ИНН («Искра»). Год не ставить: продают
  и на следующий год, а настройки года нет. Стиль может нести свои промо-страницы и свою
  раскладку наполнения (в «Модерне» — названия в две колонки).
- **Лицензии**: элементы Pro-шаблонов Canva нельзя выносить в продукт файлами; бесплатные
  элементы — в серой зоне; картинки, сгенерированные ИИ в Canva, — по AI Product Terms можно.
  Надёжнее всего — свои векторные версии по мотивам.
