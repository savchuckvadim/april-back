# Публичный конструктор по ссылке

Ссылка `https://konstructor.april-app.ru/p/<token>` открывает сборку комплекта
без Битрикса, пользователя и настроек. Её создают и отзывают в админке. КП и
документы по ней не формируются, описание комплекта скачать можно.

## Ручки

| Ручка | Кто зовёт | Что делает |
|---|---|---|
| `GET konstructor/public-links` | админка | все ссылки, новые первыми |
| `POST konstructor/public-links` | админка | создать: портал, название, срок в днях |
| `POST konstructor/public-links/:id/revoke` | админка | отозвать одну |
| `POST konstructor/public-links/revoke-all` | админка | отозвать все |
| `GET konstructor/public/:token` | Next-прокси | действует ли ссылка |
| `GET konstructor/public/:token/catalog` | Next-прокси | каталог, считается просмотром |
| `POST konstructor/public/:token/description` | Next-прокси | DOCX потоком |

## Правила

- Портал берётся из ссылки: у порталов разные договоры, регионы и меры. Домен
  наружу не отдаётся, идентификаторы Битрикса в каталоге обнулены
  (`lib/public-catalog.util.ts`).
- Отозванная, истёкшая и неизвестная ссылки снаружи неразличимы: все дают 410.
- Описание собирается тем же кодом, что во фрейме, текст из БД важнее текста
  фронта. Файл не сохраняется: текст фронта остаётся только у того, кто его
  прислал.
- Каталог кэшируется на портал на 5 минут, правка прайса доходит до страницы с
  этой задержкой. Описание ограничено 30 запросами в минуту на ссылку.

## Что отзыв не закрывает

`POST konstructor/init/data` и ручки управления ссылками открыты: guard'ов в
приложении нет. Отзыв закрывает публичную страницу и её ручки, данные каталога
остаются доступны тому, кто знает адрес API и домен портала. Закрывается это
отдельным заходом про авторизацию.
